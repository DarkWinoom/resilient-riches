# 稳健生财 · Resilient Riches

以自定义分类记录资金与收益的个人理财小应用。按自己的节奏更新各分类的余额与资金进出，直观看到持仓和收益变化。

**当前已完成 P1 工程基础。** 前后端连接、SQLite 数据库、迁移和财务计算内核已经实现；分类管理、记账表单和正式概览界面将在后续阶段接入。当前启动后显示工程连接验证页，还不能通过界面管理账本。

## 本地启动

需要 **Node.js 22.22.2 或更新的 Node 22 版本**、**pnpm 11.19.0**。项目统一使用 Node 22。

```sh
git clone https://github.com/DarkWinoom/resilient-riches.git
cd resilient-riches
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

浏览器打开 [本地应用](http://127.0.0.1:8080)。首次启动会自动创建数据库并应用迁移，后续启动保留数据。

如未安装 pnpm，可在安装 Node.js 后运行 `npm install -g pnpm@11.19.0`。

## 数据与配置

数据库默认保存为项目目录下的 `data/resilient-riches.sqlite`，不会提交到 Git。SQLite 的关联文件也由该目录保存，不要在服务运行时单独移动或复制主数据库文件。

需要改端口或数据位置时，将 `.env.example` 复制为 `.env` 后修改：

| 变量               | 默认值                           | 用途                                 |
| ------------------ | -------------------------------- | ------------------------------------ |
| `RR_HOST`          | `127.0.0.1`                      | 监听地址，默认仅本机可访问           |
| `RR_PORT`          | `8080`                           | 后端和生产页面端口                   |
| `RR_DATABASE_PATH` | `./data/resilient-riches.sqlite` | 数据库路径，相对路径以项目根目录为准 |

如需在局域网访问，可自行调整监听地址。应用不提供登录，也不区分多个用户，能够访问服务的人将能够使用后续账本功能；远程部署的入口访问控制由部署者配置。

当前使用 Node 22 内建 SQLite API，Node 会输出 `ExperimentalWarning`。本阶段已在 Node 22.22.2 上验证迁移、事务回滚、精确金额读写和数据库重开。

## 开发与检查


开发页面默认位于 [localhost:5173](http://127.0.0.1:5173)，通过代理连接后端。`.env` 中的后端端口会用于开发代理。

## 计划提供的功能

- 一个页面查看资金总览、收益曲线与分类详情。
- 自定义分类名称、颜色、期初余额、历史盈亏与备注。
- 在日历中补录、修改和删除任意历史日期的数据。
- 展示各分类上次录入日期；未录入日期自动沿用上次金额，无需每天记账。
- 扣除买入、卖出资金的影响，按每日收益率连乘计算复利收益率。
- 查看日、周、月、年收益及对应报表。
- 保存分享图片，可仅展示百分比、隐藏分类。

## 收益如何记录

需要更新时，选择日期并填写核对余额、买入和卖出金额。按照日初净投入约定：

```text
当日收益 = 当日余额 − 上次余额 − 当日买入 + 当日卖出
当日收益率 = 当日收益 ÷（上次余额 + 当日买入 − 当日卖出）
期间复利收益率 = ∏（1 + 每日收益率）− 1
```

未录入的日期自动沿用上一日金额，按无收益变动、无资金进出处理；再次录入时，扣除买入和卖出后的余额差额计入本次录入日期。周末、节假日或其他不需要更新的日期都不必额外标记，有资金进出时可在对应日期录入。

历史盈亏计入累计盈亏金额；没有历史资金和日期明细时，不据此推算历史复利收益率。

计算内核以整数分和高精度十进制运算处理金额与复利。单项金额上限为 999,999,999,999.99 元。零本金收益、资金亏光后重新投入等无法直接连乘的情况会返回明确状态，不显示无效数字；首版不使用这些数据自动推算年化收益率。
